# SIMAD — Apresentação IFSP 2026

Apresentação interativa do **Sistema Integrado de Monitoramento e Alerta de Desastres (SIMAD)**, projeto de extensão do IFSP com a Defesa Civil de Campo Limpo Paulista.

## Apresentação

- **8 slides**, seguindo os critérios de apresentação.
- **Vídeo do MVP incorporado** no arquivo HTML.
- Interface em português, com animações, navegação e QR Code do SIMAD.
- Executa localmente, sem necessidade de instalar programas ou manter uma pasta de vídeos.

**Para abrir:** baixe [index.html](./index.html) e abra no Firefox ou Chrome. O GitHub exibe o código-fonte do HTML, não executa a apresentação diretamente na visualização do arquivo.
